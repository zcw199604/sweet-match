# 内置地图

这里的 `.fpmap` 会在 `npm run build:monopoly` 时放进 `monopoly/maps/` 随站点发布，游戏里点「选择地图」会列出它们（正式版在前，文件名带「测试」的在后）。

| 文件 | 说明 |
|---|---|
| 非常好地图v0.0.11.fpmap | 正式版 |
| 非常好地图v0.1.0-测试.fpmap | 测试版 |

加新地图：把 `.fpmap` 放进这个目录，重新构建即可；旧版本不需要的可以直接删。
